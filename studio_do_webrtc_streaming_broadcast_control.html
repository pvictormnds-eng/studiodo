Como Colocar em Prática

Requisito Essencial (HTTPS): Por regras do WebRTC e navegadores móveis, as câmeras só funcionam em conexões seguras (HTTPS).

1. Hospedagem Grátis em 1 Minuto:

  • Netlify Drop: Acesse app.netlify.com/drop e arraste este arquivo index.html. Seu link HTTPS fica pronto na hora.
  • GitHub Pages: Crie um repositório no GitHub, suba o index.html e ative o GitHub Pages.

2. Adicionando ao OBS Studio / vMix:

  1. No Painel do Diretor, clique em Link OBS do repórter.
  2. No OBS, adicione uma fonte Navegador (Browser Source).
  3. Cole o link, coloque resolução 1920x1080 e marque "Controlar áudio via OBS".

3. Dica de Áudio sem Eco (Mix-Minus):

No retorno do estúdio para o repórter, envie apenas a voz do apresentador/estúdio. Não envie a voz do próprio repórter de volta para evitar microfonia.
